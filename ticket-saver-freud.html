The calendar file repeats every cleaning day until Dec 1. It sets an alarm 1 hour before each cleaning window, so your calendar reminds you in time. The parking-limit file sets one alarm 10 minutes before the limit (5 minutes for the 15-minute timer). This page can’t remind you on its own — import the file. If the window changes, delete this calendar and export again.
